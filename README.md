# 织序 AI · 交互演示

仅包含静态界面、已构建的浏览器资源与合成样例数据。

- 无需登录；支持手机与电脑屏幕。
- 主要工作台操作在浏览器内模拟；每位访问者的数据各自保存在自己的浏览器。
- 不连接真实企业软件、数据库或 AI 模型。
- 不保存密码；请勿填写真实员工资料。
- 页面下方可以重置演示数据。

## 内嵌协作概念视频

`concept-video/` 提供手机竖版多场景 MP4、中文合成旁白、中文字幕、封面与独立播放页，保留原 58 秒简版供下载。

六个情境包括上线分工、客户交付延期、报销缺材料、需求变更影响、入职准备和采购协作，最后汇入统一工作台。播放页提供章节跳转；章节信息来自同目录的 `chapters-v2.json`，加载失败不会阻断视频播放。

演示“授权群聊发现问题 → 私聊询问 → 修改草案 → 成员确认 → 工作台跟进”。界面、人物、聊天与业务状态均为概念示意，并非真实平台录屏，不表示已完成实际企业接入。

## 实拍与电脑端操作版

`concept-video/realistic-preview/` 是用户确认的新视觉方向：授权办公实拍与电脑端概念界面穿插，六个场景，约 3 分 19 秒。
当前已加入微软“云希”AI 男声和中文字幕，并根据实际语音时长对齐镜头。此前无旁白文件和早期版本继续保留。
